# BernoInfo 2026

A neutral, sourced guide to the 2026 municipal election in Bernolákovo, Slovakia.

The repository is private during research and development. Nothing is published automatically. The initial product direction is a Slovak-language, mobile-first React/TypeScript site on Cloudflare Pages, with selective GSAP, Lenis, and React Bits use that respects reduced-motion settings. Cloudflare deployment is a later, separately reviewed step.

Start with [the project charter](docs/PROJECT_CHARTER.md), [research protocol](docs/RESEARCH_PROTOCOL.md), and [agent workflow](docs/AGENT_TEAM.md).
